# Antifraud — Real-time Transaction Fraud Detection

Система обработки транзакций в реальном времени с детекцией мошенничества. Транзакции принимаются через API, проходят через очередь сообщений, скорятся на предмет подозрительности и сохраняются в базу. Параллельно работает фоновый процесс переобучения модели.

## Архитектура

```
Client → FastAPI → Kafka → Consumer (scoring) → PostgreSQL
                                                      ↑
                                              Airflow (retrain)
```

**Быстрый путь** (реальное время): API принимает транзакцию и сразу кладёт её в Kafka, не блокируясь на обработке. Consumer забирает сообщение из очереди, прогоняет через скоринг и сохраняет результат в базу.

**Медленный путь** (батч): Airflow раз в сутки пересчитывает статистику мерчантов и дообучает модель на накопленных данных.

| Слой | Технологии |

| API | FastAPI, Pydantic, Uvicorn |
| Хранилище | PostgreSQL 17 + PostGIS, SQLAlchemy 2.0 (async), Alembic |

| Оркестрация | Airflow |
| Инфраструктура | Docker Compose |

## Модель данных

**Payer** — плательщик. Хранит профиль: имя, домашнюю локацию (геоточка PostGIS), средний чек, дату создания аккаунта. Профиль нужен, чтобы отличать нормальное поведение от аномального: сумма 50 000 ₸ подозрительна у того, чей средний чек 3 000 ₸.

**Merchant** — получатель платежа. Название, категория (заправка, ювелирный, e-commerce), исторический процент фрода, средняя сумма транзакции. Категория важна, потому что «нормальная» сумма сильно зависит от типа бизнеса.

**Transaction** — событие платежа. Сумма, валюта, время, ссылки на плательщика и мерчанта, статус обработки (`pending` / `scored`) и вердикт скоринга.

Геоданные хранятся в PostGIS (`geography(Point, 4326)`) с GIST-индексом — это позволяет считать расстояние между локацией транзакции и домашней локацией плательщика средствами базы.

## Запуск

```bash
# Инфраструктура
docker compose up -d

# Зависимости
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Миграции
alembic upgrade head

# API
uvicorn api.main:app --reload
```

Документация API: http://localhost:8000/docs

### Переменные окружения

Создайте `.env` в корне проекта:

```
POSTGRES_USER=...
POSTGRES_PASSWORD=...
POSTGRES_DB=...
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/dbname
```

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/merchants/` | Создать мерчанта |
| GET | `/merchants/{id}` | Получить мерчанта |
| POST | `/payers/` | Создать плательщика (принимает `latitude` / `longitude`) |
| GET | `/payers/{id}` | Получить плательщика |
| POST | `/transactions/` | Создать транзакцию |
