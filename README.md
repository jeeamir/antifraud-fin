# Antifraud — Real-time Transaction Fraud Detection

Система обработки транзакций в реальном времени с детекцией мошенничества. Транзакции принимаются через API, проходят через очередь сообщений, скорятся на предмет подозрительности и сохраняются в базу. Параллельно работает фоновый процесс переобучения модели.

## Архитектура

```
Client → FastAPI → Kafka → Consumer (scoring) → PostgreSQL
                                                      ↑
                                              Airflow (retrain)
```

**Быстрый путь** (реальное время): API принимает транзакцию и сразу кладёт её в Kafka, не блокируясь на обработке. Consumer забирает сообщение из очереди, прогоняет через скоринг и сохраняет результат в базу.

**Медленный путь** (батч): Airflow раз в сутки пересчитывает статистику мерчантов и дообучает модель на накопленных данных.

## Стек

| Слой | Технологии |
|---|---|
| API | FastAPI, Pydantic, Uvicorn |
| Хранилище | PostgreSQL 17 + PostGIS, SQLAlchemy 2.0 (async), Alembic |
| Очередь | Apache Kafka (KRaft) |
| Оркестрация | Airflow |
| Инфраструктура | Docker Compose |
